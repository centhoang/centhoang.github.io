HandyDrive
What it does Google account access Availability Privacy policy

Free up disk space without losing anything.

HandyDrive is a Windows tool that moves big folders and git repos to your own Google Drive, encrypted, and brings them back to the same place when you need them.

Privacy policy How it uses your Google account

Windows 10 and 11. It runs entirely on your PC: there is no HandyDrive server or account, and the developer never receives your files or data.

What it does

HandyDrive stores what you give it in an encrypted, deduplicated repository inside your Google Drive, so uploading again only sends what changed.

Park a git repo

Checks that nothing would be lost (everything committed and pushed), uploads the git-ignored files, verifies the upload, then deletes the folder to free the space. hgd unpark clones the repo back and restores the ignored files to the same path.

Sync any file or folder

Upload a file or folder from anywhere, free its space (keep it cloud-only), restore it, or stop syncing. Explorer shows a small icon on each synced item and a right-click HandyDrive menu offers what applies.

Built to be careful with your data

  • Encrypted before upload. Your files are encrypted on your PC with a key only you hold. Google stores unreadable data.
  • Verified before delete. Nothing is removed from your disk until the uploaded copy has been checked against it.
  • Cloud-only items never download on open. A freed item is an empty file or folder until you restore it.
  • Deletes are permanent. When you remove something from the cloud, it doesn't linger in the Drive trash, so the space comes back at once.

How HandyDrive uses your Google account

HandyDrive asks for one permission, https://www.googleapis.com/auth/drive.file. With it, the app can only see and change files that it created in your Drive. It cannot read your other files, and it does not request your name, email address, contacts or any other profile data.

It uses that access only to store and retrieve the data you choose to park or sync: an encrypted storage folder and a small readable text note per item, all inside a HandyDrive folder in My Drive. Your data goes only to your Google Drive; nothing is shared, sold or used for advertising.

The full details, including what each note contains and how to remove everything, are in the privacy policy.

Availability

HandyDrive is a personal project and isn't distributed publicly at the moment. It is set up by connecting it to a Google Cloud OAuth client and a Google account that belong to the person using it, so the app is always tied to that person's own project and Drive.

Setup signs in with Google and creates a recovery key that only the user holds. Without it, the encrypted data in Drive can't be read, by the user or anyone else.

Questions about this page or the privacy policy are welcome as GitHub issues.
